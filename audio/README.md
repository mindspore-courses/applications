## 音频应用

本目录包含基于MindSpore 2.7.1版本+动态图+mint接口构建的即用型音频应用笔记。每个笔记演示了完整或部分工作流程（训练、微调或推理），并简要介绍了所用模型。

### 应用列表

| 编号 | Model | 课程描述 |
| :-- | :---- | :------- |
| 1 | [WaveNet](./wavenet/) | 包含用于 WaveNet 训练的笔记本，涵盖音频合成等任务 |
| 2 | [Wav2Vec2](./wav2vec2/) | 包含用于 Wav2Vec2 微调的笔记本，涵盖音频意图分类等任务 (MInDS-14) |

### 贡献新的音频应用

贡献新的音频应用方法：

1. 请将您的笔记本放入对应的模型目录中。
2. 若模型尚未拥有独立目录，请按现有结构创建新目录。
3. 遵循贡献指南中的 notebook 编写与命名规范。
4. 如需要，更新 README 中的应用程序列表。
